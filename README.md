# beyond_news
news analisys platform specialized on korean environment.

I hope my service can help you farm informations in this super-personalized sociaty.

## CI/CD (EC2 + GitHub Actions)

- 워크플로우: `.github/workflows/ci-cd.yml`
- 인프라/보안 문서: `infra/aws/README.md`, `infra/aws/SECRETS.md`
- IAM 정책 샘플: `infra/aws/*.json`
- 배포 스크립트: `scripts/deploy.sh`
- 프로덕션 컴포즈: `docker-compose.prod.yml`
